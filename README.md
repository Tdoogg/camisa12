# camisa12
ITF (Índice de Torcedor Fiscal) é um protótipo acadêmico de app web que mostra à torcida a transparência financeira de clubes de futebol brasileiros. Cada clube recebe uma nota de 0 a 100, calculada com base em receitas, despesas, dívida, salários e governança. Tem login, ranking, comparativo, gráficos, alertas e layout responsivo. Dados
